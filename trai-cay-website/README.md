# PHÁT TRIỂN WEBSITE CỬA HÀNG TRÁI CÂY 🫐
Website **Cửa hàng trái cây** được biết đến với công dụng tìm kiếm mọi loại trái cây mà khách hàng *muốn* và đưa ra những loại trái cây *phù hợp* với mọi loại khách hàng.   
## Thư mục và nội dung của website: 
| Thư mục | Nội dung|
| :---: | :---: |
| `docs` | Chứa thông tin nguồn hàng |
| `media` | Chứa logo trái cây sạch |
| `data` | Chứa dữ liệu excel bán trái cây sạch tháng 7 |
## Nội dung dự án 
```powershell 
 Get-ChildItem -Recurse -Force
 ```
